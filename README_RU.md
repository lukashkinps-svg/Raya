# Райя-Прайм: первый анимированный прототип для Windows 11

## Запуск
1. Установите Python 3.11 или 3.12 с python.org, включив опцию **Add python.exe to PATH** / установив Python Launcher.
2. Распакуйте архив целиком в отдельную папку.
3. Дважды нажмите `start_windows.bat`. При первом запуске программа установит пакет Pillow (нужен интернет).
4. Райя появится в отдельном прозрачном окне поверх рабочего стола.

## Что уже работает
- Аватар Райи в PNG с прозрачностью.
- Плавающее окно поверх других окон.
- Перетаскивание персонажа левой кнопкой мыши.
- Лёгкая анимация ожидания (движение вверх-вниз). Моргание временно отключено до подготовки отдельных слоёв глаз.
- Реплика по клику; правый клик открывает меню; Esc — закрыть.

## Чего пока нет
- Настоящей Live2D-модели и независимого движения волос/лица/рта.
- Активации голосом, речи, ИИ-ответов, анализа экрана и управления компьютером.
- Переноса на Android.

Это **первый запускаемый прототип аватара**, а не законченная версия умного помощника. Для полноценной анимации следующая задача — подготовить многослойный рисунок и сделать риг.

## Замечания
- Проверено по структуре и синтаксису, но запуск в Windows 11 в этой среде не тестировался.
- Исходный образ основан на пользовательском референсе. Перед публичным распространением стоит проверить права на персонажа и изображения.

## Обновление v0.1.4: логи, настройки, подготовка к обновлениям
- Ошибки приложения и запуск/завершение записываются в `logs/raya.log` (UTF-8, ротация: ~1 МБ, до 3 резервных файлов).
- Ошибки Python и установка зависимостей пишутся в `logs/launcher.log`.
- Позиция аватара и настройка покачивания сохраняются в `data/settings.json`.
- ПКМ по аватару → «Открыть папку логов».
- Новый `update_windows.bat`: вызывает `git pull --ff-only` и обновляет зависимости **только если папка связана с настоящим Git-репозиторием**.

### Как обходиться без скачивания ZIP каждый раз
Для автоматического обновления нужно **сначала опубликовать исходники в репозитории** (например GitHub); сейчас адрес репозитория Райи-Прайм ещё не задан, поэтому кнопка обновления пока честно сообщает, что обновлять неоткуда. Никаких тайных скачиваний нет.

После публикации репозитория один раз установите Git для Windows и клонируйте проект с помощью `git clone <URL_репозитория>`, затем запускайте `update_windows.bat` в этой папке. Папки `data/` и `logs/` желательно исключить из Git через `.gitignore`; не коммитьте свои личные логи. На время обновления рекомендуется закрыть Райю.

Временный вариант до публикации: положите новые отдельные файлы `raya.py`, `start_windows.bat` и `update_windows.bat` в существующую папку Райи, подтвердив замену. Папку `assets` и ваши `data`/`logs` не трогайте.
